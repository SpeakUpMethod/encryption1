Vault

A password vault that lives in one encrypted file on your own device. No autofill, no cloud — but generate, store, search, and copy, all local.

This password protects everything in the vault. If you lose it, there is no way to recover the vault's contents — nothing is sent anywhere that could reset it.

● Unsaved changes
Vault tries to clear copied passwords from the clipboard after 30 seconds. Browsers may block this once you've switched tabs, so on a shared computer, copy something else when you're done.

Add Entry

Your vault is one encrypted file — nothing is ever uploaded. Save it somewhere you'll remember (your own cloud folder, a USB drive) since there's no account to recover it from.
