Token

Generate the same time-based (TOTP) codes as Google Authenticator or Authy. Everything happens in this browser tab — nothing is sent anywhere.

This is usually shown as text underneath a QR code when setting up two-factor authentication — look for a "can't scan?" or "enter manually" option.

------
Advanced settings

Only change these if the service told you to use something other than the standard 6-digit, 30-second setup — most services never require this. If you pasted a full otpauth:// URI, its own settings are used automatically and these are ignored.

Treat this secret like a password. Anyone with it can generate valid codes for your account, same as this tool does. It's never transmitted or saved — it exists only in this browser tab until you clear it or close the page.
Token implements the standard TOTP algorithm (RFC 6238) — the exact same math every authenticator app uses. Codes generated here will match codes from any other authenticator app using the same secret, since both are just independently computing the same formula from the same starting point.
