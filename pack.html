How Pack works, and its limits

Pack puts files and whole folders into one locked file, a package. On another computer, open this page, choose the package and enter the password to get everything back, folders and all.

  • Stays on your device. Your files are read and encrypted inside this browser tab. Nothing is uploaded, and a saved copy of this page works offline.
  • Everything is locked. File names, folder names, dates and contents are all inside the encryption (AES-256-GCM, with the password strengthened by 600,000 rounds of PBKDF2). From the outside, a package only shows its size.
  • Any change is caught. The package is sealed in 1 MB pieces, each with its own check. If a piece is changed, missing, added or moved, or the end is cut off, it won't open. Every file is also compared with its fingerprint (SHA-256) when you save it.
  • Big folders are fine. Chrome and Edge on a computer write the package straight to disk, so the size is only limited by free space. Safari, Firefox and phones build it in memory first, so keep packages made there under about 1.5 GB.
  • Forgot the password? Then no one can open the package. There is no reset and no back door. Keep the password somewhere safe.

What Pack doesn't do: It doesn't make files smaller, doesn't hide how big the package is, and can't protect files on a computer that already has malware. Packages use the new .e1pack format; older .pvault files open in Encryption 1 or Multi-File.
