How File Truth works, and what it can’t do

Every kind of file starts with its own tell-tale bytes: a PDF starts with “%PDF”, a Windows program with “MZ”, a ZIP with “PK”. File Truth reads those bytes, and for some files a little more, then compares what it finds with the file’s name.

  • Disguised programs. A program renamed “invoice.pdf”, a shortcut called “Contract.docx”, or “photo.jpg.exe” all show up for what they are.
  • Risky documents. Office files with macros, PDFs that run scripts or launch other programs, and RTF files with embedded packages are flagged, because these are common ways to deliver malware.
  • Phishing attachments. Web-page attachments (.html) that contain a password form, or that send what you type to another site, are a favourite way to steal logins.
  • Archives and disk images. Inside ZIP files, File Truth lists programs, scripts and disguised names. Disk images (.iso, .img, .vhd) and password-protected archives are flagged because they are used to slip files past email scanners.

Limits. File Truth is not an antivirus. A file can be exactly what its name says and still be harmful, and a careful attacker can hide things this check can’t see, such as code inside compressed parts of a PDF or inside RAR and 7z archives. Use it as a first look, keep your device’s own protection on, and only open files you expected from people you trust. The fingerprint link sends only the file’s SHA-256 fingerprint to VirusTotal when you click it, never the file.

File Truth works offline and can be saved and run from a USB stick like the other Encryption 1™ tools.
