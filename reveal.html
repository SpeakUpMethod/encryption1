How Reveal works, and what it can’t do

Computers store every letter as a number. Many different numbers can look the same on screen: the Latin “a” and the Cyrillic “а” are different characters that most fonts draw identically. Some characters draw nothing at all. Scammers use both to write words that you read one way and a computer reads another.

  • Invisible characters such as zero-width spaces split words like “Verify” so spam filters miss them.
  • Direction controls reverse how letters are shown, so a program file can be displayed as if it ended in “.pdf”.
  • Tag characters can carry a whole sentence that you cannot see but that some programs can extract and read.
  • Lookalike letters from Cyrillic, Greek, Armenian or Cherokee are swapped into English words and web addresses.
  • Disguised web addresses put a brand name in front of someone else’s domain, or hide the real destination after an “@”.

How serious is it? These characters also have ordinary uses, so Reveal looks at where each one appears. “Danger” is kept for combinations with a clear purpose, such as a company name spelled with lookalike letters, a program file disguised as a document, or a whole hidden sentence. “Careful” means a pattern that is sometimes used to disguise text but can also be innocent. “Note” and “Normal” are listed so you can see everything that is there.

Reveal knows where these characters are normal. A joiner inside an emoji or in Hindi or Persian text, a narrow space before “!” in French, and right-to-left marks in Arabic or Hebrew text are recognised as ordinary and not flagged.

Limits. A clean result means none of these tricks were found. It does not prove a message is honest: a scam can use a completely ordinary address that simply isn’t the company’s. Reveal checks the text you give it; it never opens links, so it cannot see where a link would finally lead. The list of companies it recognises is short, and addresses are compared with a public list of domain endings that is built into this page.

Files. Plain text files are checked as they are. For email files (.eml), Reveal reads the sender and subject lines and each text or HTML part, including parts in “base64” or “quoted-printable” encoding, and lists any attachments it did not check. Web pages are checked as source text: styling is not applied, so text hidden with colours or tiny fonts shows up here as ordinary text and is not flagged.

Reveal works offline and can be saved and run from a USB stick like the other Encryption 1™ tools. Brand checks cover a short list of commonly imitated companies; an address that isn’t flagged still deserves a second look if you weren’t expecting the message.
