About the Encryption 1™ Suite

What is in the Suite?
  • Encryption 1™ encrypts text or a file with a password.
  • Multi Files encrypts up to 5 files at once.
  • EC-1 Personal Journal keeps a private, encrypted diary.
  • Vault keeps your passwords in one encrypted file that you own.
  • Burn sends a message or photo that can be opened only once.
  • Fingerprint checks whether two files are exactly the same.
  • Scrub removes hidden information, such as location and author names, from photos and documents.
  • Forge creates strong passwords and passphrases.
  • Token creates two-factor login codes.
  • Clarify points out clauses in contracts and Terms of Service that deserve a closer look.
Is it free?

Yes. Every tool is free, with no account, no trial period and no paid version. If you find the Suite useful, you can support it with an optional donation through Ko-fi; this helps pay for hosting, translations and new features. The video tutorial series is sold separately on Ko-fi.

Is the source code available?

Yes. The source code is released under the MIT License, so anyone can read and check exactly what the tools do.

Which languages are available?

The website and tools are available in 23 languages. Two things stay in English by design: Clarify, because its checks are written for English-language contracts and English-speaking legal systems, and Forge’s passphrase word list, which is a carefully tested English list.

What’s the difference between Encryption 1™, Multi Files and the Journal?

Encryption 1™ encrypts one piece of text or one file at a time. Multi Files does the same for up to 5 files at once. The Journal is for writing private entries that are saved in encrypted form. All three use the same encryption.

Encrypting files and text

What kinds of files can I encrypt?

Almost any: Word documents, Excel spreadsheets, PDFs, images, ZIP files, text files and more. The tool doesn’t need to understand what is inside the file; it encrypts the file’s bytes.

Is there a size limit?

Yes. Each file can be up to 10 MB. Multi Files can encrypt up to 5 such files at once. To encrypt more files, put them in a ZIP file first; the tool treats a ZIP file as a single file. The limit keeps the browser-based tool light and reliable.

Can I encrypt images?

Yes. JPG, PNG, GIF and other image files can be encrypted like any other file, as long as each is within the 10 MB limit.

Can I encrypt Word and Excel files?

Yes. The tool encrypts the file itself. When you decrypt it, you get back the original file with its original name and file type.

Can I encrypt PDFs and ZIP files?

Yes, as long as each file is no larger than 10 MB.

Where can I learn how to use it step by step?

See the how-to guide, written in plain language with no technical background needed.

Privacy, storage, and the Internet

Are my files uploaded to a server?

No. Encryption and decryption happen in your browser. The server never receives, stores or sees the contents of the files you encrypt. The one tool that uses the server is Burn, and it sends only an encrypted message that we cannot read (see below).

Do I need an account?

No. There is no account, signup or login.

Does it need an Internet connection?

Only to load the page. The encryption itself happens in your browser, not on a remote service. For use without the Internet, download the free Portable Edition from the Downloads page; it works offline in any browser that supports the Web Crypto API. Burn is the only tool that always needs the Internet.

Do I have to install anything?

No. The tools run in your web browser. The Portable Edition is a folder of web pages that you open in your browser; nothing is installed.

Can I carry it on a USB drive?

Yes. Copy the Portable Edition to a USB drive and you can use it on almost any computer, without installing anything and without leaving your files on that computer.

Can I move an encrypted file by email, USB drive or cloud storage?

Yes. The encrypted .pvault package is an ordinary file and can be moved like any other. Keep the password separate from the file.

Does the site use cookies or tracking?

No tracking, no advertising and no analytics service. The only exception is the optional Ko-fi donation button, which comes from Ko-fi and may set its own cookies. Details are in the Privacy Policy.

Passwords and decryption

What happens if I forget my password?

The encrypted content cannot be recovered. We never have a copy of your password, so nobody, including us, can open the file without it. This is an important part of how the tools protect your privacy.

Can it create a strong password for me?

Yes. Click Generate next to the password field, or use Vault or Forge. Save the password somewhere safe before you use it; it isn’t stored anywhere else.

Can I change the password on an encrypted file?

Not directly. Decrypt the file with the old password, then encrypt the original file again with the new one.

Can I send an encrypted file to someone else?

Yes. The other person needs the encrypted file and the correct password. For better security, send the password a different way than the file, for example by phone or text message if you emailed the file.

Can Encryption 1™ break or recover a password?

No. It is not a password-recovery service. If the correct password is lost, the content cannot be recovered.

Vault, Burn and Token

Where does Vault keep my passwords?

In one encrypted file that you save: on your computer, a USB drive, a cloud folder, or several of these. It is never sent to us. Because the file is encrypted with your master password, it stays protected even if someone else gets a copy.

What if I forget my Vault master password?

Your vault cannot be opened. Choose a master password you will remember, and keep a backup copy of your vault file.

Does Vault save automatically or fill in passwords on websites?

No to both. Click Save after making changes; unsaved changes are lost when Vault locks itself. Filling in passwords on websites would require a browser extension, which works very differently from the rest of the Suite. Vault is currently in beta.

Can you read my Burn messages?

No. A Burn message or photo is encrypted in your browser before it is sent, and the key exists only in the link you share. Our server stores only the encrypted version, which it cannot read.

What happens to a Burn message after it is opened?

It is deleted from the server the moment it is opened, and nobody can open it again. A message that is never opened is deleted automatically after 7 days.

Does Token remember my accounts?

No. Token does not save your secret key; when you close or reload the page, it is gone. Keep the secret key, or your account’s recovery codes, somewhere safe, such as Vault.

What it can and cannot protect

Does encryption protect the file itself?

The tools protect the contents of the encrypted package using AES-GCM with a key made from your password. That is strong protection, but it is not a guarantee against every possible threat.

Does it protect me from phishing?

No. Encryption protects data. It does not protect anyone from being tricked into revealing a password, opening a malicious attachment, or sending information to a scammer.

Does it protect me if my computer has malware or a keylogger?

No. If an attacker can see what you type or open the files on your device, encryption on that device cannot solve the problem. Use an up-to-date, trusted device whenever possible.

Does it protect against accidental deletion or a lost USB drive?

No. Encryption protects privacy, not availability. Keep safe backups of important encrypted files.

Is it “unbreakable”?

No security tool should make that claim. The Suite uses modern, strong encryption, but overall security also depends on your password, your device, your surroundings, and how you handle the encrypted files.

How to use it more safely

  • Use a strong, unique password or passphrase.
  • Don’t reuse a password from email, banking, social media or another important account.
  • If you send an encrypted file, send its password a different way.
  • Avoid handling sensitive material on public or untrusted computers.
  • Keep safe backups of important encrypted files and of your Vault file.
  • Be careful with file names. A file name can reveal information even when the contents are encrypted.
  • Before sharing a photo or document, use Scrub to remove hidden information such as location and author names.
  • Remember that encryption does not protect against phishing, social engineering, malware or careless password handling.
