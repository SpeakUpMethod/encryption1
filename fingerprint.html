Fingerprint

Generate a verifiable fingerprint for a file, or check a file against one you saved earlier — up to five at once. Everything happens in this browser tab; nothing is uploaded.

SHA-256 gives a 64-character fingerprint and is the most widely recognized standard (Bitcoin, TLS certificates, Git) — a good default. SHA-512 gives a longer 128-character fingerprint and can run faster on modern 64-bit hardware for large files. Both fully detect any change, no matter how small.

Drop up to 5 files here, or click to choose Processed locally · up to 200MB per file

Algorithm is detected automatically from the length of the fingerprint you paste — no need to select it.
